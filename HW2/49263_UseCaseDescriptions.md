# UC-01 설문 등록

액터 (Actor)

관리자

목표 (Goal)

관리자가 단일 문항 객관식 설문을 등록한다.

| no. | actor action | system response |
| --- | --- | --- |
| 1 | 설문 등록 메뉴를 선택한다. | - |
| 2 | - | 설문 등록 화면을 출력한다. |
| 3 | 설문 주제와 항목 수를 입력한다. | - |
| 4 | - | 입력한 설문 주제와 항목 수를 출력한다. |

# UC-02 설문 응답

액터 (Actor)

회원

목표 (Goal)

회원이 설문 리스트 중 하나의 설문에 대해 항목 번호를 선택하여 응답한다.

| no. | actor action | system response |
| --- | --- | --- |
| 1 | 설문 응답 메뉴를 선택한다. | - |
| 2 | - | 설문 응답 화면을 출력한다. |
| 3 | 설문 주제와 응답 항목 번호를 입력한다. | - |
| 4 | - | 입력한 설문 주제와 응답 항목 번호를 출력한다. |

# UC-03 응답한 설문 조회

액터 (Actor)

회원

목표 (Goal)

회원이 자신이 응답한 모든 설문 정보를 조회한다.

| no. | actor action | system response |
| --- | --- | --- |
| 1 | 응답한 설문 조회 메뉴를 선택한다. | - |
| 2 | - | 모든 응답한 설문 내역 리스트를 출력한다. 각 설문에 대해 설문 주제와 응답 항목 번호가 출력된다. |
